How to use this app

📊 Simulator

  1. Set your pickems. Open the Pickems menu and choose which teams go 3-0, which qualify (3-1 / 3-2), and which go 0-3.
  2. Update real match results (if any). Click the winning team in the bracket to lock in matches that have already been played in real life.
  3. Simulate. Press Simulate from current state (1000×) to run the Monte Carlo simulation from wherever the bracket currently stands.
  4. View the Statistics tab. See your pickem success chances along with in-depth stats for every team — qualification %, record distribution and likely opponents.

🎯 Predictions

The Predictions page is a separate game: predict the real winner of each match, then mark it ✓ Correct (+3 points) or ✗ Wrong once it's played. It does not affect the Simulator in any way.
